GET STARTED

Principles

제품에서 검증하고, 반복되는 것만 시스템으로 승격합니다.
01

Clear over clever

업무 UI에서는 장식보다 상태와 다음 행동을 분명하게 전달합니다.

02

Accessible by default

키보드, 포커스, 명도 대비와 스크린리더 의미를 기본값으로 둡니다.

03

Token driven

색상과 간격을 직접 쓰지 않고 의미 기반 토큰을 소비합니다.

04

Composable

작은 Primitive를 조합해 복잡한 업무 패턴을 만듭니다.

QUALITY

Accessibility

WCAG 2.2 AA를 목표로 하고 자동검사와 수동 키보드 검증을 함께 수행합니다.
  • 모든 조작 요소의 가시적인 :focus-visible
  • 텍스트·UI 상태의 명도 대비 검증
  • Dialog 포커스 이동과 Escape 종료
  • 상태를 색상 하나로만 전달하지 않음
  • Label, Description, Error의 프로그램적 연결
  • 동작 감소 설정 prefers-reduced-motion 지원
저장했습니다변경사항이 반영되었습니다.
